# Lessons Learned

## Version Control and Branching

- I learned how to clone a repository and work with Git branches.
- I learned how to create separate branches for different changes.
- I learned how to push local branches to GitHub.

## Merge Conflicts

- I learned that conflicts can happen when two branches modify the same lines.
- I learned how to identify conflict markers in VS Code.
- I learned how to combine the required changes and remove duplicate code.
- I learned to use `git status` to verify that conflicts have been resolved before committing.

## Pull Requests

- I learned how to create a pull request from a feature branch to `main`.
- I learned how to use the PR Diff to review differences between branches.
- I learned how to describe conflict resolution in a pull request.
- I learned how to merge a pull request into `main`.

## Future Improvements

In future projects, I will make smaller and more frequent commits, review branch differences before merging, and test the application after resolving conflicts.
